# 기상 조건이 강원도 화재 발생 및 피해 규모에 미치는 영향 분석

PCA 기반 포아송 GLM과 상호작용 MLR을 이용한 빈도·심도 통합 모델링

- **과목**: IMEN415 Multivariate Analysis, 고려대학교 산업경영공학부 (2026-1)
- **유형**: 3인 팀 프로젝트 (Final Project)
- **언어/도구**: R (tidyverse, ggplot2, zoo 등), R Markdown

## 연구 질문

1. 기상 변수들의 복합 요인(주성분)과 계절은 화재 발생 빈도에 유의한 영향을 미치는가?
2. 영동/영서 지역 간에 풍속이 화재 피해 규모에 미치는 영향이 다른가? (양간지풍에 해당하는 지형–풍속 상호작용 검정)

## 데이터

| 데이터 | 출처 | 내용 |
|---|---|---|
| 화재 발생 정보 (2015–2024) | [소방청 국가화재정보시스템 (공공데이터포털)](https://www.data.go.kr) | 강원도 18개 시군구 화재 발생 일시, 인명·재산 피해 |

## 방법 및 주요 결과

### 가설 1 — 화재 발생 빈도 (PCA + Poisson GLM)

- 상관된 5개 기상 변수(평균기온·평균습도·최대풍속·건조지수·기온교차)를 PCA로 축약. PC1(한랭·건조 지수) + PC2(돌풍·일교차 지수)가 전체 분산의 **69.4%** 설명
- 화재 '발생 여부(0/1)' 로지스틱 회귀에서 시작해, 다발성(multiplicity)을 반영하지 못하는 한계를 확인하고 '발생 건수'를 종속변수로 하는 **포아송 회귀로 전환**
- 세 설명변수 모두 유의 (p < 0.001): PC2 1단위 증가 시 일일 발생 건수 **약 +23%**, PC1 **약 +12.5%**, 봄철 더미 **약 +10%** (기상 조건과 독립적인 기저 위험 상승)
- 과대산포 점검: Pearson dispersion ratio = 2.32 → 음이항 회귀 비교를 향후 과제로 명시

### 가설 2 — 화재 피해 규모 (상호작용 MLR)

- 재산피해액의 우측 편포를 로그 변환으로 완화, Cook's Distance(4/N 기준)로 영향점 제거 (11,823 → 11,298행)
- 풍속 × 지역(영동/영서) 상호작용 항 유의 (β = +0.168, p < 0.001): 풍속의 효과가 영서 −0.089에서 영동 +0.079로 **부호 역전**
- 영동에서 풍속 1 m/s 증가 시 피해 규모 약 +8.2% (e^0.079 ≈ 1.082) — 양간지풍(푄 현상)의 지형 효과를 데이터로 확인
- FWL 정리 기반 편회귀 분석으로 상호작용 모형 결과를 교차 검증 (지역별 기울기 −0.09 / +0.086로 일치)
